# 42 Piscine

My exercises from the **42 Piscine** at 42 Heilbronn: the intensive four-week selection bootcamp where I learned C from scratch.

During the Piscine every exercise is written without the standard library (only `write` and later `malloc` are allowed), follows the 42 coding standard (Norminette) and is evaluated by other students and an automated grader.

## Modules

| Module | Topic | Exercises |
| :--- | :--- | :--- |
| [C00](./C00) | First steps with `write` | `ft_putchar`, `ft_print_alphabet`, `ft_print_reverse_alphabet`, `ft_print_numbers`, `ft_is_negative` |
| [C01](./C01) | Pointers | `ft_ft`, `ft_ultimate_ft`, `ft_swap`, `ft_div_mod`, `ft_ultimate_div_mod`, `ft_putstr`, `ft_strlen` |
| [C02](./C02) | String handling | `ft_strcpy`, `ft_strncpy`, `ft_str_is_alpha`, `ft_str_is_numeric`, `ft_str_is_lowercase`, `ft_str_is_uppercase`, `ft_str_is_printable`, `ft_strupcase`, `ft_strlowcase` |
| [C03](./C03) | Comparing & concatenating strings | `ft_strcmp`, `ft_strncmp`, `ft_strcat`, `ft_strncat` |
| [C04](./C04) | Output of strings & numbers | `ft_strlen`, `ft_putstr`, `ft_putnbr` |
| [C05](./C05) | Recursion & math | `ft_iterative_factorial`, `ft_recursive_factorial`, `ft_iterative_power`, `ft_recursive_power`, `ft_fibonacci`, `ft_sqrt` |
| [C06](./C06) | Command-line arguments (`argc` / `argv`) | `ft_print_programm_name`, `ft_print_params`, `ft_rev_params` |
| [C07](./C07) | Dynamic memory with `malloc` | `ft_strdup`, `ft_range`, `ft_ultimate_range`, `ft_strjoin` |

The [drafts](./drafts) folder contains earlier working versions that are not part of the submitted exercises.
